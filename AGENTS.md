# Checkout. — ASMR culture site

Course project (資訊文化與消費) promoting ASMR culture. Mobile-first web app,
deployed to **Vercel**. The owner is not a programmer: explain changes in plain
Traditional Chinese, and ask before making decisions that are hard to undo.

> This project was originally generated by Figma Make and has since been moved
> out of it. Figma-specific rules (`buildFigmaConfig`, `figma make verify-deploy`,
> platform-owned env vars, etc.) **no longer apply**.

## Stack

- Next.js 16 (App Router) + React 19 + Tailwind CSS v4
- Payload CMS 4 (beta) for the sound library and `/admin`
- Node.js ≥ 24.22, pnpm

## Structure

- `src/app/(frontend)/` — public site
  - `layout.tsx` — shared frame: Header + page body + Footer (+ aurora, headphone gate, player)
  - Page bodies (one file each, they only list sections in order):
    `page.tsx` (home), `about/page.tsx`, `archive/page.tsx`, `experience/page.tsx`
  - `content.ts` — ALL copy and navigation (siteNav drives both Header and Footer). Edit text here.
  - `styles.css` — design tokens (`@theme`), aurora background, shared component classes
  - `components/Header.tsx`, `components/Footer.tsx` — site header / footer
  - `components/sections/` — page sections (Hero, Gateways, About, Glossary, Timeline,
    Sociology, MatchQuiz, SoundLab, Library)
  - `components/site/` — site-wide behaviour (Aurora, HeadphoneGate, Player provider, RevealObserver, UploadDialog)
  - `components/ui/` — small shared pieces (Icon, CheckoutLogo, SectionHeading, MiniWave)
  - `submit-track/route.ts` — public upload endpoint (creates `pending` tracks)
- `src/imports/` — external assets supplied by the team (e.g. `checkout-logo.svg`).
  Replace files here instead of editing components; the logo is rendered as a mask so its colour follows text colour.
- `src/lib/events.ts` — small cross-section signals (quiz → mixer preset / library filter)
- `src/lib/tracks.ts` — cached query for approved tracks
- `src/lib/synth.ts` — Web Audio synthesis of trigger sounds (rain, tapping, …) and
  the "only one sound at a time" bus (`claimAudio` / `onAudioClaimed`)
- `src/collections/AsmrTracks.ts` — sound library schema (moderation via `status`)
- `src/app/(payload)/` — generated by Payload, do not edit

## Design rules

- Night × aurora: dark background `night`, accents `aurora-mint/cyan/violet/rose`.
- Calm motion only: slow easing (`--ease-calm`), no flashing; respect `prefers-reduced-motion`.
- Every change must work on phone (≈375px), tablet and desktop. Check for horizontal
  overflow (`document.documentElement.scrollWidth` must equal the viewport width).
- Respect iPhone safe areas (`env(safe-area-inset-*)`); inputs use ≥16px font.
- Library audio uses a plain `<audio>` element (NOT routed through Web Audio) so it keeps
  playing with the screen locked. Lab sounds use Web Audio.

## Data & deployment (Vercel)

- Database: Postgres via `@payloadcms/db-postgres` (Neon). `push: false` — schema changes
  MUST be done with migrations: edit collections, then `pnpm migrate:create <name>` and commit
  the files in `src/migrations/`. `pnpm build` runs `payload migrate` before building.
- Files: Vercel Blob via `@payloadcms/storage-vercel-blob`, configured in the top-level
  `storage` array of `payload.config.ts` (Payload 4 moved storage adapters out of `plugins`).
  Disabled when `BLOB_READ_WRITE_TOKEN` is missing (falls back to local disk).
- Env vars: `PAYLOAD_SECRET`, `DATABASE_URL` (or `POSTGRES_URL`), `BLOB_READ_WRITE_TOKEN`.
  See `.env.example` and `DEPLOY.md`.
- Local dev uses the same Neon database as production unless a separate branch/URL is set.
